# Old files archive (2026-10-10)

This archive contains the 824-file gamma scalping and grid hedging inventory, including related historical research, data, and documents gathered from the local Strat workspace and the doubleCapital repository. It preserves the material for review and later keep/discard decisions.

The ZIP is split into three parts because the complete file exceeds GitHub's per-file limit. Download all three parts into one directory, then reconstruct it:

    cat all_inventory_2026-10-10.zip.part-* > all_inventory_2026-10-10.zip
    shasum -a 256 all_inventory_2026-10-10.zip

Expected SHA-256: cf0eec7605ed23377856187f1e2870744853636f35ae91e7cda775db6df1d5b5

The ZIP contains INVENTORY_REVIEW.md and FULL_MANIFEST.csv. Paths inside the ZIP identify their original source. This archive includes material from the private doubleCapital repository and is stored in this public repository at the owner's direction.
